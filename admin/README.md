# KALKAN SPORT · Панель администратора (Admin Console)

Премиальная веб-панель управления платформой **KALKAN SPORT** в стилистике *Obsidian Athletic (Whoop 5.0 & Oura Precision)*.

Предназначена для мониторинга биометрии, управления пользователями и часами **СААТ-1**, анализа тренировок, администрирования приватных лиг и рассылки системных push-уведомлений.

---

## 🚀 Способы запуска

### Способ 1: Мгновенно в браузере (без установки пакетов)
Просто откройте файл `admin/index.html` двойным кликом в Google Chrome, Safari или Edge.  
Панель сразу готова к работе со всеми графиками, фильтрами и симулятором.

---

### Способ 2: Через Node.js сервер
```bash
cd admin
npm install
npm start
```
Сервер запустится по адресу: **http://localhost:3000**

---

### Способ 3: Через Python HTTP-сервер
```bash
cd admin
python -m http.server 3000
```
Откройте в браузере: **http://localhost:3000**

---

### Способ 4: Деплой в Firebase Hosting
Вы можете разместить панель на бесплатном домене Firebase Hosting:
```bash
firebase deploy --only hosting
```

---

## 🧩 Основные разделы и возможности

| Раздел | Возможности |
|---|---|
| **Обзор (Overview)** | Ключевые KPI (всего атлетов, активные, средний Recovery, средний Strain), интерактивный график недельной нагрузки и пульса, распределение по зонам готовности (зелёная, жёлтая, красная), живая лента событий. |
| **Атлеты (Athletes)** | Таблица всех пользователей, поиск по имени/email, фильтры по полу и зонам готовности. Редактирование роста, веса, пола, сброс 14-дневной калибровки baseline, симуляция замера СААТ-1, удаление. |
| **Телеметрия СААТ-1** | Биометрическая матрица: пульс покоя, HRV (мс), индекс готовности, фазы сна (глубокий сон, REM), статус связи с часами и заряд батареи. |
| **Тренировки (Workouts)** | Журнал тренировок: бег на улице, беговая дорожка, велоспорт, силовые, плавание, HIIT. Метрики дистанции, пульсовых зон, калорий и Strain. |
| **Лиги и Партнёры** | Мониторинг приватных лиг Данбара, таблица лидеров, 6-значные коды связки (инвайты) и статус синхронизации партнёрских пар. |
| **Пуш-уведомления** | Отправка сообщений через Firebase Cloud Messaging (FCM). Готовые шаблоны (утренний отчёт, зарядка часов, рекомендация отдыха). Таргетинг по аудиториям. |
| **Настройки и Экспорт** | Переключатель между **Live Firestore** (`watch-ba720`) и **Демо-симулятором**, экспорт всей базы данных в **CSV** и **JSON**, импорт бэкапов. |

---

## 🔒 Настройка доступа к Firebase Firestore

По умолчанию в панели настроена конфигурация проекта `watch-ba720`:
- **Live Firestore Mode**: При включении тумблера в настройках панель считывает реальную коллекцию `users` из облачной базы данных Firebase.
- **Demo Mode**: Позволяет демонстрировать возможности панели офлайн, клиентам или инвесторам с реалистичными данными 10+ атлетов.
- **Сервисный аккаунт (опционально)**: Для отправки пушей через сервер положите файл `service-account.json` (из консоли Firebase -> Project Settings -> Service accounts) в папку `admin/`.
